# LeaseLens AI

A local-first, AI-assisted property operations platform. This is an independent portfolio project built with fictional, synthetic data only.

## Status

Work in progress. Phase 1 (frontend shell and dashboard) is under way. All numbers shown in the UI are demo data and are labelled as such.

## Planned stack

React, TypeScript, Vite, Tailwind CSS, FastAPI, PostgreSQL with pgvector, and local models through Ollama.

## Run the frontend

    cd frontend
    npm install
    npm run dev
